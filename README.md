# ArdeaNew WPF Minimal UI Design

A portable Agent Skill for designing and refining minimalist WPF desktop interfaces.

It guides compatible coding agents through:

- Solid-color surfaces by default
- Compact, consistent spacing and layout density
- Workflow-driven module arrangement
- Restrained shadows and cursor behavior
- Windows-oriented typography and font fallback
- In-window dropdown and popup placement
- Concise interface copy
- Avoiding unnecessary buttons and low-necessity features
- MVVM-friendly XAML implementation

## Structure

```text
SKILL.md
references/
├── wpf-design-principles.md
├── wpf-font-system.md
├── wpf-xaml-patterns.md
└── validation-checklist.md
```

## Codex

Copy the skill directory into the project or user skill directory, then restart Codex:

```text
.codex/skills/ardeanew-wpf-minimal-ui-design/SKILL.md
```

Invoke it explicitly with:

```text
Use $ardeanew-wpf-minimal-ui-design to design this WPF screen.
```

## OpenCode

Copy the skill directory into the project or user skill directory, then restart OpenCode:

```text
.opencode/skills/ardeanew-wpf-minimal-ui-design/SKILL.md
```

Invoke it explicitly with:

```text
@ardeanew-wpf-minimal-ui-design design this WPF screen.
```
